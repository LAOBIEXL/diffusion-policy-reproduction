# Push-T 视觉仿真复现协议

日期：2026-10-16。实验对象为 DiffusionPolicy-C 的 Push-T 视觉控制策略，使用作者公开的 epoch=500 EMA 权重。

## 模型与控制

视觉编码器使用 ResNet18、GroupNorm 和 SpatialSoftmax。条件一维 U-Net 通道为 512 / 1024 / 2048，总模型参数为 262,709,026。

输入为最近两帧图像和推动器位置。图像分辨率 96×96，编码器裁剪为 84×84。DDPM 使用 100 个去噪步骤生成长度 16 的二维位置动作序列，每次执行其中 8 步，再根据新观测生成下一段动作。

模型加载 EMA 参数及检查点中的归一化统计，使用 FP32 推理。随机种子从检查点读取。

## 环境与评测

- Push-T 使用 `legacy_test=true`。
- 测试初始条件：seed=4300000–4300049，共 50 个。
- 同时执行配置中的 6 个训练环境初始条件，单独记录其指标。
- 并行环境数：56。
- 每回合上限：300 个环境动作步。
- 每回合记录最大 reward，跨 50 个测试回合求平均。

设第 i 个回合在时刻 t 的几何目标覆盖率为 c(i,t)，则：

```text
reward(i,t) = clip(c(i,t) / 0.95, 0, 1)
score(i) = max_t reward(i,t)
test_mean_score = mean_i score(i)
```

得分反映归一化目标覆盖程度。逐回合结果按环境种子与官方日志配对比较，同时报告本机平均分、官方平均分和差值。
