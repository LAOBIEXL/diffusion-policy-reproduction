# Push-T 视觉仿真复现结果

使用作者公开的 epoch=500 EMA 权重，在 50 个官方测试初始条件上运行闭环控制。

| 指标 | 结果 |
| --- | ---: |
| 官方平均得分 | 0.883584 |
| 本机平均得分 | 0.918845 |
| 得分差值（本机 − 官方） | +0.035261 |
| 测试回合数 | 50 |
| 评测用时 | 96.63 s |
| 峰值 GPU 分配内存 | 1136.01 MiB |

环境种子为 4300000–4300049，与官方日志逐项对齐。每回合上限 300 步，DDPM 采样 100 步，执行时域 8 步。得分为每回合最大归一化目标覆盖率的平均值。

运行环境：NVIDIA GeForce RTX 5070 Laptop GPU，PyTorch 2.11.0+cu128，CUDA 12.8，Python 3.10.20。

官方日志记录训练期间的评测，本次从检查点配置的随机种子重新初始化采样。DDPM 动作采样的随机数状态及 PyTorch / CUDA 版本差异可能影响生成的轨迹与得分。

逐回合比较见 [episodes.csv](episodes.csv)，完整输出见 [eval_log.json](eval_log.json)，实际配置见 [evaluation_config.yaml](evaluation_config.yaml)。
